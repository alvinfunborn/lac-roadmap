# 地点日期与 Day N

地点每次访问的日期是实际安排。线路起止日期从已排日期的地点推导；空线路可以先保存计划日期。

- 整条线路没有日期时，按 `days = N` 分组。没有日序号的地点默认 Day 1。
- 首次给线路设日期，以 Day 1 为基准展开所有天；首次给某个地点设日期，以它原来的 Day N 为基准展开所有天。
- 线路已有日期时，没有日期的地点属于「未安排」。修改某个地点日期只影响该次访问。
- 编辑线路并清空日期时，清空全部地点起止日期，按原日期间隔还原 Day N。原未安排地点保持相对顺序，放入最后一天。
- 修改已安排线路的开始日期，整体平移已安排地点，保留具体时刻和跨日结束时间；未安排项仍未安排。

日期和日序号属于每次访问，保存在对应线路的地点引用下。共享地点文件保留名称、描述、坐标等通用信息。例如同一酒店的两次访问：

```toml
[[酒店]]
start_time = "2026-10-01"
[[酒店]]
start_time = "2026-10-03"
```

清空线路日期后保存为：

```toml
[[酒店]]
days = 1
[[酒店]]
days = 3
```
