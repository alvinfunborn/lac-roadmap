## 2. RoadmapSet 页
### 2.1 卡片排序
- 未安排在上，已安排在下
- 未安排区：文本顺序倒序
- 已安排区：时间倒序；同时间则文本倒序

### 2.2 拖拽
- 仅未安排的卡片可拖拽
- 松手后仍在未安排区内排序，写回根文件 [[...]] 顺序

## 3. Roadmap 页
### 3.1 卡片排序
- 文本顺序正序 + 时间正序
- 冲突时：时间大的文本视为在时间小的文本之后

### 3.2 拖拽
- 可拖拽排序，松手后：修改 items 顺序；若有时间则改为列表里上一有时间的卡片的时间; 若没有列表上一个有时间的卡片, 则检查时间是否大于列表下一个有时间的卡片的时间, 是的话改成这个时间

### 3.3 新增地点
- 新增地点要写到正确的文本顺序里

## 4. days 字段
- 用于无 start_time 的地点，表示第几天
- 存于地点 [detail]；编辑器不展示，可自动推断
