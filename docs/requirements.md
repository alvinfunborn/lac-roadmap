# LaC Roadmap 需求文档

> 基于 `draft.md` 与当前实现整理，用于完整实现本插件。

---

## 1. 产品定位

**旅行路线规划与记录插件**：在 Obsidian 内以 TOML + 双链 Markdown 管理路线集合（roadmapset）、单条路线（roadmap）与地点（place），通过地图与按日/按 tab 的视图进行规划与回顾。

---

## 2. 设计规范（来自 draft）

### 2.1 主题色

| 用途           | 色值       | 说明           |
|----------------|------------|----------------|
| 背景色         | `#101820`  | 主背景         |
| 已开始/已结束  | `#b3995d`  | 状态：已完成   |
| 未开始         | `#d3bc8d`  | 状态：计划中   |
| 未安排         | `#FF8200`  | 状态：未安排   |
| 卡片背景       | `#4b4b4b`  | 辅助色         |
| 警告色         | `#aa0000`  | 危险/警告      |
| 纯白           | `#ffffff`  | 高对比元素     |

### 2.2 地图与布局

- **顶部地图**：宽高比 **1:1**（draft 明确 1:1；当前实现为 3:2，可配置或按 draft 改为 1:1）。
- **卡片右侧小图**：**1:1**，单点或聚合点，与 draft 一致。
- 地图提供商：**Google 地图**（draft）；实现支持 Google / 高德，可切换。

## 4. 数据与文件格式（与 draft 一致）

### 4.1 根文件（如 `roadmap.md`）

- `type = "root"`
- `renders = ["roadmapset"]`
- 正文：`[[日本之行]]` 等双链，表示集合中的 roadmap。

### 4.2 路线文件（如 `日本之行.md`）

- `name`、`type = "root"`、`renders = ["roadmap"]`
- `[detail]`：`description`、`start_time`、`end_time`、`address`
- 正文：`[[银座]]`、`[[秋叶原]]`，可选紧随 `route = { travelMode, distance, duration, tolls }`。

### 4.3 地点文件（如 `银座.md`）

- `name`
- `[detail]`：`start_time`、`end_time`、`description`、`address = { name, ... }`（可含经纬度）
- 子地点：`[[银座药局]]`、`[[银座奶茶]]` 及可选的 `route = { ... }`。

### 4.4 字段语义

- **travelMode**：walk | bicycle | two_wheeler | drive | transit（与 draft 一致；代码中为 `two_wheeler`，draft 为 `two_wheeler`）。
- **route**：上一链接地点到当前地点之间的路段信息。
